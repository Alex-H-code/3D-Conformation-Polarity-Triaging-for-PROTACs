# Experimental Methods

**Compound library.** The starting virtual library was assembled by combinatorial enumeration of heterobifunctional degraders, pairing E3-ligase binder, linker, and POI-ligand fragments. This set was reduced by sequential application of standard 2D physicochemical filters (molecular weight, calculated LogP/LogD, hydrogen-bond donor/acceptor count, topological polar surface area, rotatable bond count) followed by a synthetic-accessibility filter, yielding 2,300 candidate compounds carried forward for conformational analysis.

**Conformer generation.** For each of the 2,300 compounds, 3,000 conformers were generated by distance-geometry embedding (RDKit 2026.03.1, GPU-accelerated via the nvmolkit extension v0.5.1) and energy-minimized using the MMFF94 force field in vacuo (no explicit or implicit solvent model). Batch size for MMFF minimization was fixed at 200 conformers per GPU call; unbatched minimization produced illegal-memory-access errors, while batches of 1,000 exceeded available GPU memory. A fixed random seed (42) was used for embedding reproducibility. Generation was distributed across 23 Slurm array tasks (100 compounds each) on three NVIDIA A30 GPU nodes.

**Boltzmann weighting.** Each compound's 3,000-conformer ensemble was Boltzmann-weighted by relative MMFF energy at 298 K:

*w_i = e^(−E_i/RT) / Σ_{j=1}^{N} e^(−E_j/RT)*

where *w_i* is the Boltzmann weight assigned to conformer *i*, *E_i* is the MMFF energy of conformer *i* relative to that compound's lowest-energy conformer (subtracted before exponentiation for numerical stability), *R* is the gas constant, *T* = 298 K, and *N* is the total number of conformers in the ensemble (3,000).

**3D descriptor calculation.** One conformer-dependent descriptor was computed for every conformer and combined into a Boltzmann-weighted, per-compound average:

- *Radius of gyration (Rgyr)*: computed with RDKit's `Descriptors3D.RadiusOfGyration` (mass-weighted, derived from the principal moments of inertia per Todeschini and Consonni, not the simple root-mean-square distance from the center of mass), including all explicit hydrogens.
- *Solvent-accessible 3D polar surface area (3D-PSA)*: computed in PyMOL (pymol-open-source v3.1.0, RDKit 2026.03.5) using the dot-solvent SASA algorithm (1.4 Å probe radius, dot density 3), summing the contribution of O, N, and any H atom bonded to O/N.

Boltzmann-weighted per-compound descriptor averages were computed as ⟨*A*⟩ = Σᵢ *w_i*·*A_i* / Σᵢ *w_i*, where *A_i* is the descriptor value (Rgyr or 3D-PSA) for conformer *i*; the explicit renormalization by Σᵢ*w_i* accounts for any conformers dropped from the analysis due to failed descriptor calculation. Population diversity of each compound's conformer ensemble was summarized by the effective sample size (Kish's ESS = 1/Σ*w_i*²) and the maximum single-conformer Boltzmann weight.

For storage and downstream compute efficiency, only the 50 highest-Boltzmann-weight conformers per compound were retained in the final per-conformer output after full-ensemble weighting and descriptor calculation.

**Validation of 3D-PSA calculations.** Because 3D-PSA values are sensitive to the specific SASA implementation, PyMOL-derived values were independently cross-checked against a second SASA calculation using RDKit's FreeSASA wrapper (`rdFreeSASA`), applying the same 1.4 Å probe radius and the same O/N(+H) polar-atom definition. Because RDKit's built-in atom-radius classifier is parameterized for protein residues and fails silently (returning zero) on non-protein small molecules, atomic radii were instead assigned explicitly by element using standard Bondi-type van der Waals radii. This cross-check was performed in two stages: (1) a stratified spot-check of 25 compounds sampled evenly across the full ranking distribution, using each compound's single highest-Boltzmann-weight conformer, and (2) a full validation across all retained conformers for all 2,300 compounds (~115,000 conformers total). Agreement between the two methods was summarized as percent difference, (PyMOL − FreeSASA)/FreeSASA × 100.

**Literature-informed filtering.** Descriptor thresholds associated with passive membrane permeability in heterobifunctional degraders were taken from Kim, Sheridan, Zhang, Barros, Johnston, and Xiao (2025), who derived 3D-descriptor windows from well-tempered metadynamics simulations of 32 degraders in explicit chloroform with experimentally measured Caco-2 permeability. An analogous window (Rgyr 4.5–6.0 Å; 3D-PSA 135–230 Å²) was applied to the present 2,300-compound set using the Boltzmann-weighted, per-compound Rgyr and 3D-PSA values. Because the PyMOL and FreeSASA 3D-PSA calculations differed systematically (see Results), filtering was performed using the arithmetic mean of the two values per compound; results using the FreeSASA-only value are reported separately for comparison.

25-ADMET-endpoint machine-learning predictions (clearance across species, permeability assays, plasma protein binding, CYP inhibition, LogP/LogD) from a previously trained model were reported alongside the filtered set as additional context, but reported as a separate, independent metric rather than merged with the 3D-descriptor filtering criteria.

**Structural diversity analysis.** Chemical diversity within the filtered compound set was assessed using Morgan (circular) fingerprints (radius 2, 2,048 bits; RDKit `rdFingerprintGenerator`) and Butina clustering on pairwise Tanimoto distance. Clustering was performed twice: once on the full degrader structure (similarity threshold 0.85, the conventional cutoff for whole-molecule structural series) and once on the isolated linker fragment alone, extracted with its attachment-point placeholders (similarity threshold 0.70, adjusted for the smaller fragment size). An initial whole-molecule clustering at a lower, conventional default threshold (0.6) was found to be uninformative for this library, collapsing nearly all compounds into a single cluster due to large invariant warhead scaffolds shared across the combinatorial set; this motivated the higher threshold and the separate linker-only analysis reported.

**Software and computing environment.** Conformer generation, MMFF minimization, and Boltzmann weighting were performed with RDKit 2026.03.1 and the nvmolkit GPU extension (v0.5.1) in a dedicated conda environment (`nvmolkit`). 3D-PSA calculations used PyMOL (pymol-open-source v3.1.0) via its `pymol2` Python API, alongside RDKit 2026.03.5, in a separate conda environment (`pymol_env`).
